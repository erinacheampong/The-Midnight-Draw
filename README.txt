HOW TO DEPLOY TO YOUR EXISTING GITHUB PAGES REPO
1. Download and unzip this package.
2. In your GitHub repo, upload the five HTML files plus CNAME and .nojekyll to the repository root.
3. Upload the entire assets folder, preserving:
   assets/css/styles.css
   assets/js/site.js
   assets/images/...
4. It is okay to leave the older unused image files in the repo while testing.
5. Commit everything to main.
6. Wait for GitHub Pages to deploy, then hard refresh:
   Windows: Ctrl + Shift + R
   Mac: Command + Shift + R
7. Test:
   - Home | About | Gallery | FAQ | Contact on every page
   - All booking/inquiry buttons go to contact.html
   - Instagram goes to @themidnightdraw
   - FAQ expands one answer at a time
   - Contact form submits and shows an inline success message
   - Mobile layout is readable
